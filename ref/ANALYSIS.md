## 炮台区（简报说 5 列——实测是 **6 列** 队列 + **5 个**白色圆形槽位）
- 6 列队首（f0）：黑 / 绿 / 紫 / 黄 / 绿 / 黑，屏幕 (250,880) (305,862) (368,850) (425,840) (485,826) (543,815)；
  每列可见约 14 个，列向右下延伸（地面反投影：列间距≈2.8 单位，行距≈2.0 单位，列方向≈+z）。
- 5 个槽位（白色圆盘）：(253,848) (312,833) (370,822) (428,812) (487,800)，位于 1–5 列队首的上方。
- 炮台造型（放大核对）：两侧履带 + 圆角车身 + 圆顶炮塔 + 短炮管 + 白色描边数字（共 6 个元素），卡通黑描边；队首数字清晰，后排数字半透明。
- 弹药：全部 200（54 s 内看到的新炮台都是 200）。

## 规则（逐帧核实，与简报不同处加粗）
1. **点击**（不是按住）某列队首 → 炮台跳到**最左侧空槽位**（0.4 s：黄 → 槽 1；1.2 s：黑 → 槽 2；2 s：绿 → 槽 3）。
2. 槽位里的炮台**自动连续射击**，只打**同色**方块：绿打绿条/菱形，黑打黑线，紫打紫壳，黄打黄色夹层。
   没有可打的同色外露方块时**原地等待**（黄色 0.4 s 进槽，一直等到 ~20 s 黑线被打开、黄色露出才开火）。
3. 射速：绿色 199@3s → 163@6s → 127@9s → 91@12s ≈ **12 发/秒**；目标少时更慢（黑 ≈9/s，黄 ≈4.7/s，受外露数量限制）。绿色在 24–30 s 停在 45（没有外露的绿色）。
4. 白色小球从炮口射向目标方块，命中即消除该方块（同时出现少量同色碎屑），**小球弹开**沿弧线飞散并下落淡出（成串的“珠链”效果来自连续发射的球沿相近轨迹弹开）。
5. 弹药打光（47.5–50 s 紫色 → 0）：炮台缩小/飞离，槽位重新变白；空出的槽位可再放新炮台。
6. 队列：被点走的队首由后一个前移补位。
7. 54 s 结束时未通关（外壳被打掉约一半），视频里**没有胜负画面**；胜利 = 方块全部消除（按玩法），失败（同类玩法）= 5 槽全满且都无目标可打。
8. 手：2D 卡通手（规范：默认用麻将工具的手图），点击时按下缩小。
